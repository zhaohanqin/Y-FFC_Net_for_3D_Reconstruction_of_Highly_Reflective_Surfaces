# 消融实验 A：去除频域模块（ABLATION_no_frequency）

**文件**：`Y_FFC_no_frequency.py` / `train_no_frequency.py`
**对照**：完整 YFFC（baseline `train.py`，建议加同种子 42 重跑）

## 为什么这么做

完整模型在编码器瓶颈、梯度解码器（H/16、H/8、H/4）、主解码器（FFC1/FFC2、ffc_h8、ffc_h4）和增强层四类位置共使用了十余处 FFC。FFC 的核心假设是：FFT 后在频域做 1×1 卷积等价于**全图范围的特征混合**，对周期性结构光条纹（频域为离散谱峰）和大面积高光区域的全局推理特别有利。

本实验把 FFC 全局分支的频域核心 `SpectralTransform` 替换为构造签名、输入输出通道完全一致的纯空间卷积块（1×1 → 3×3 → 膨胀 3×3 残差 → 1×1），通过一处 monkey-patch 让全网所有 FFC 位置同时失去 FFT。FFC 的 L/G 双分支拓扑、四路交互、跨域门控全部保留——**唯一被改变的是"频域全局混合"这一种运算**。

## 这样有什么效果（如何解读）

- 性能下降（尤其大面积高光中心的填充质量、条纹周期一致性、`freq` 子损失偏高）→ 证明频域全局感受野是有效来源；
- 基本不变 → 提示全局信息可能已由 Swin 分支提供，FFC 冗余，可裁剪提速；
- 反而提升 → 提示 FFT 路径的数值不稳定/频谱泄漏带来的负作用大于收益。

## 为什么能与完整模型严格区分（体现结构优越性）

1. **单变量**：替代块参数量与原频域路径同量级且**略高**——若消融模型性能仍下降，就不能用"容量减少"来解释，只能归因于失去频域全局建模，结论比"直接删模块"更强；
2. 频域**损失** `l_freq` 保持不变（它是监督信号，不是结构），避免把"损失消融"混进"结构消融"；
3. 参数名仍含 `ffc`，分层学习率分组与 baseline 一致；数据、增强、调度、种子全部一致。

## 训练方式

```bash
python train_no_frequency.py
```

注意：本模型文件导入时会 patch `Y_FFC_unified.SpectralTransform`，请勿在同一进程内同时构建 baseline 模型。

### 0.2 全片叙事主线（一段话）

> 结构光条纹投影（FPP）测三维时，**高反光表面会破坏条纹的正弦性**：过曝区把正弦峰谷"削平"成亮度平台，非过曝区让条纹局部畸变、错相。条纹一旦不再"干净正弦"，相位解算就会解错，最终变成点云上的尖刺与深度误差。
> 因此本工作的定位是：**在高反光条件下，把被破坏的条纹恢复成"可用于相位解算的物理正确条纹"**——不是做"好看的去高光图"，而是做"**面向三维重建的物理结构恢复**"。
> 为此提出 **X-FFC-Swin**：用 **ResNet50 + Swin-Tiny 双编码器**同时抓局部纹理与全局窗口上下文；用 **FFC 频域卷积**（贯穿编码器瓶颈、两个解码器、增强层与损失）从全图周期结构推断"被高光破坏处本应是什么条纹"；用 **梯度辅助分支**回答"该在哪里修"；用 **高反光概率头 s** 把"边缘"进一步判别为"是否高反光相关"；用 **双头解码 + 残差精修**避免"减法链脆弱"；用 **6 组高反光感知复合损失**完成多任务监督。最后接 **相位分析工具链 → 绝对相位 → 点云误差**，用可量化指标证明精度提升。

### 0.3 三大贡献（整片要反复回扣）

1. **物理先验驱动的双域解耦**：频域管"修成什么样"（正弦性/周期/全局相位一致性），梯度管"在哪里修"（高光边界/平台/污染区定位），二者在结构上同时进入编码、解码、增强与损失，而非作为后处理拼装。
2. **高反光语义的三级放大**：`输入梯度 g`（哪里异常） → `高光软概率 s`（是否高反光相关） → `增强特征 enh`（如何修正高光分量），让"强梯度 ≠ 高反光"的歧义被显式判别。
3. **双路径漫反射恢复**：`r_sub = clamp(x − b)` 物理一致性路径 + `r_direct` 直接恢复路径 + `alpha` 可学习融合 + `ResidualRefinementHead` 残差精修，规避单一减法链的误差放大。

### P5 · 应用背景：为什么要做高反光表面的三维重建
- **页码 / 归属**：P5 / Part 1
- **页面目标**：让听众理解"高反光测量"是真实工业刚需，不是学术玩具。
- **版式建议**：上排 4 张实拍图（金属叶片 / 铰链 / 抛光件 / 反光涂层），下排 3 个痛点短句；右栏一句"本工作切入点"。
- **标题区**：**研究背景 · 高反光表面的三维测量难题**
- **正文要点**：
  - 适用场景：航空发动机叶片、飞机铰链、精密金属件、抛光模具、带涂层的工业零件。
  - 结构光/条纹投影（FPP）是非接触式高精度三维测量的主流方案，但**高反光表面的镜面反射会严重破坏投影条纹**。
  - 典型后果：过曝饱和、条纹削顶、局部畸变、相位跳变、点云空洞与尖刺。
  - 传统对策的局限：喷涂哑光粉（破坏表面/不可在线）、多曝光融合（提高动态范围但不恢复正弦性）、偏振/多视角（设备复杂、仍不解决条纹形变）。
  - **本工作切入点**：用深度网络在**图像域恢复"物理正确的条纹"**，再用成熟的相位/点云流程完成重建。
- **图 / 表 / 公式**：左侧实拍图建议取自 `data2/inputs` 或论文图；右侧一张"喷涂 vs 本方法"示意对比。
- **数据来源 / 需补充**：⚠️ 场景应用图请用户补充或从论文 PDF 截取（项目内无 PDF）。
- **讲稿要点**：点出"高反光测量的失败往往是**相位失败**，而不是图像不美观"。

### P6 · 问题定义：从"图像去高光"到"条纹正弦性恢复"
- **页码 / 归属**：P6 / Part 1
- **页面目标**：把任务定义纠正为"物理结构恢复"，这是全片立论基础。
- **版式建议**：左右分栏。左侧"常见误解"，右侧"本工作定义"；底部一行公式带。
- **标题区**：**问题定义 · 我们恢复的是条纹的物理结构，而不是好看的图像**
- **正文要点**：
  - 理想成像模型：`I_i(x,y) = A(x,y) + B(x,y)·cos[φ(x,y) + δ_i]`，i = 1..N（本文数据为 N = 4 步）。
  - 高反光分解模型：`I(x,y) = I_d(x,y) + I_s(x,y)`。
  - 高反光对条纹的**两类破坏**：
    1. **过曝饱和区**：正弦峰谷被"削平"，形成亮度平台，正弦性丧失；
    2. **非过曝但被干扰区**：未饱和，但条纹不再是稳定正弦——出现局部畸变、波动、错相。
  - **关键论断**：真正影响重建精度的是"**条纹正弦特性被破坏**"，而不仅是"哪里过曝"。只处理过曝亮度、不恢复正弦性，相位依旧会解错。
  - 因此任务目标应形式化为：`r ≈ I_d`，且 `r` 必须在条纹周期、相位关系、灰度过渡上满足正弦条纹规律。
- **图 / 表 / 公式**：
  - 建议配一张"同一行灰度剖面"三联图：正常条纹（标准正弦）/ 过曝区（平台+削顶）/ 非过曝污染区（畸变波动）。
  - 公式带：`I = A + Σ_{i=1..k} B_i·cos(iφ)`（高反光条纹的非正弦展开，k > 1）。
- **数据来源 / 需补充**：结论与公式出自 `docs\Y_FFC_X_FFC_频域_梯度_详细分析总结_最终版.md`。⚠️ 剖面图建议用 `phase_analysis\fringe_gray_analysis.py` 在真实样本上生成，最有说服力。
- **讲稿要点**：这一页是全场最重要的"定义页"，讲慢一点，后面所有设计都要回扣这页。
- **现有 PPT 复用**：页 3（任务定义）大幅改写升级——旧版只讲"分解为漫反射与高反光"，新版加"正弦性被破坏"与剖面证据。

### P7 · 高反光在频域的表现：为什么频谱会"变脏"
- **页码 / 归属**：P7 / Part 1
- **页面目标**：为 FFC 的引入提供**物理必然性**（不是"因为 FFC 流行"）。
- **版式建议**：左侧一张"干净频谱 vs 脏频谱"示意，右侧"频域成分对照表"（6 行）。
- **标题区**：**高反光的频域表征 · 频谱为什么变脏**
- **正文要点**：
  - 干净条纹的频谱：能量集中在设计投影频率附近（窄峰）+ 携带三维信息的低频相位/频率调制。
  - 高反光让频谱出现**三类污染**：
    1. **低频/DC 增强**：来自大面积过曝平台（削顶后不再零均值）；
    2. **高频增强**：来自"正常区 → 过曝区"的亮度突变边界；
    3. **高次谐波增加**：来自削顶与非正弦畸变。
  - 频域成分对照表（**保留 / 抑制**决策）：

| 频域成分 | 物理来源 | 是否携带三维信息 | 处理策略 |
|---|---|---|---|
| 正常投影条纹主频 | 投影仪设计的条纹 | 是 | **保留** |
| 深度调制的频率/相位缓变 | 物体表面形貌 | 是（核心） | **保留** |
| 大面积过曝亮斑（低频/DC） | 镜面反射饱和 | 否 | **识别为高光干扰，抑制** |
| 过曝边界突变（高频） | 正常区↔饱和区跳变 | 否 | **定位高光边界后抑制** |
| 削顶非正弦条纹（谐波） | 饱和截断/畸变 | 否 | **抑制，恢复基频正弦** |
| 噪声划痕（高频杂散） | 传感器/表面缺陷 | 否 | 与真实边界区分后抑制 |

  - 结论：高光**同时**带来低频与高频污染（内部平台 + 边缘突变 + 谐波），这正是必须用频域全局建模来处理它的原因。
- **图 / 表 / 公式**：
  - 建议图：一行灰度图的 FFT 幅值谱（对数坐标）三联——干净条纹 / 过曝条纹 / 非过曝污染条纹。
  - `F{dI/dx} = j2πf · F{I}`（为下一页梯度铺垫）。
- **数据来源 / 需补充**：分析框架来自 `docs\Y_FFC_X_FFC_频域_梯度_详细分析总结_最终版.md`。⚠️ 频谱截图可用 numpy FFT 在真实样本上现算（本环境无法执行 Python，请用户在本地生成后插图）。
- **讲稿要点**："高光不是一味的高频或低频，它是**低频平台 + 高频边界 + 谐波**的叠加，单一滤波器无法处理。"

### P8 · 高反光在梯度域的表现：为什么还要一条梯度支路
- **页码 / 归属**：P8 / Part 1
- **页面目标**：说明梯度分支的不可替代性，并给出"频域 vs 梯度"的清晰分工。
- **版式建议**：上方"梯度区域对照表"（6 行）；下方左右对比卡："频域管什么 / 梯度管什么"。
- **标题区**：**高反光的梯度表征 · 频域解决"修成什么样"，梯度解决"在哪里修"**
- **正文要点**：
  - 梯度定义：`∇I = (∂I/∂x, ∂I/∂y)`，幅值 `|∇I| = sqrt(I_x² + I_y²)`。
  - 理想条纹的梯度也是**稳定周期规律**：`dI/dx = −2πfB·sin(2πfx + φ)`，最大值出现在**亮暗过渡斜坡中部**，而不是亮峰/暗谷。
  - 高反光如何破坏梯度规律：
    1. 过曝平台**内部**梯度趋近 0（信息被抹平，需要补全）；
    2. 过曝平台**边界**梯度极大（需要重点处理）；
    3. 非过曝污染区梯度**杂乱/尖峰**（需要修复而非简单抹除）。
  - 梯度区域对照表：

| 区域类型 | 梯度表现 | 该不该动 |
|---|---|---|
| 正常条纹过渡带 | 大且规律 | 保留 |
| 正常亮峰/暗谷附近 | 小 | **不应误判为高光** |
| 过曝高光内部 | ≈ 0 | 需补全条纹 |
| 高光/过曝边界 | 很大 | 重点处理、精准定位 |
| 非过曝高光干扰区 | 杂乱、尖峰、不规律 | 需修复 |
| 物体几何边缘/深度突变 | 大 | 谨慎保留（真实结构） |

  - **分工结论**：
    - **频域**回答"整张图是不是合理的正弦条纹图"（主频、谐波、额外低频、异常高频、全局相位周期连贯性）→ 决定**修成什么样**；
    - **梯度**回答"每个位置的灰度变化方式是否符合正常条纹规律"（哪里变化快慢、边界在哪、平台在哪、是否局部畸变）→ 决定**在哪里修**。
    - 只有频域 → 定位不精确；只有梯度 → 不知道应该恢复成什么周期与相位。
  - 二维完整展开式（可选放页脚）：`∇I = ∇A + ∇B·cos(φ+δ) − B·sin(φ+δ)·∇φ + ∇I_s`，其中 `∇I_s` 是镜面反射引入的额外梯度，是"高反光任务的关键干扰项"。
- **图 / 表 / 公式**：建议配一张"同一行灰度 + 其梯度幅值"的双轴图，标出亮峰、暗谷、斜坡、平台、边界五类位置。
- **数据来源 / 需补充**：来自 `docs\Y_FFC_X_FFC_频域_梯度_详细分析总结_最终版.md`。⚠️ 双轴图需本地生成。
- **讲稿要点**：这一页是"频域 + 梯度双分支"的立论页，建议用一句话收尾："**频域决定目标形态，梯度决定作用位置，缺一不可。**"
- **现有 PPT 复用**：新增页（旧版直接讲 GradientDecoder 结构，缺此动机）。

### P10 · 总体架构 · 文字详细说明
- **页码 / 归属**：P10 / Part 2
- **页面目标**：用文字把架构图的"信息流"讲清楚，方便不看图也能理解。
- **版式建议**：三段式布局（编码 / 解码与桥接 / 输出与监督），每段 4–5 条。
- **标题区**：**总体架构 · 信息流文字说明**
- **正文要点**：
  - **编码阶段**：ResNet50 提取局部纹理与边缘，形成多尺度 skip；Swin-Tiny 直接在原分辨率尺度上处理单通道 patch，提供窗口化全局上下文；两条支路在 H/4、H/8 用 `AdaptiveSkipFusion` 注入、在 H/16 用 `CrossModalFusion` 做双向交叉融合；融合结果经 `cba_after_backbone → FFC bottleneck → HighFrequencyEnhancement` 形成瓶颈 `x_c`。
  - **深层回灌**：`CrossScaleTopDownRefinement` 把 H/16 的全局上下文（含高光区域判断）以受限残差方式回流到 H/8、H/4 的浅层 skip（`gamma` 初值 0.05，clamp 到 0~0.2）。
  - **任务分解阶段**：`GradientDecoder` 复用同一套编码特征，多尺度输出结构/梯度特征 `xe_1..4`，并在末端并列两个头：梯度头（`g`，监督 `Sobel(I)`）与高光概率头（`s`，监督 `gt_specular = clamp(I − I_d, 0, 1)`）。
  - **桥接阶段**：`EnhancementLayers` 的 `_SpectralDecompositionUnit` 把 `xe_i` 变成"对高光分解更有用"的 `enh_i`，判别依据是 `g + 原图亮度 + s` 三路门控。
  - **恢复阶段**：`MainDecoder` 逐级上采样，每级做"频域残差 + 梯度/高光门控调制 + 高光感知注意力 + skip 门控 + 拼增强特征"，最后双头输出 `b` 与 `r_direct`，并给出 `alpha` 融合权重，经 `ResidualRefinementHead` 得到最终 `r`。
  - **监督阶段**：6 组子损失 + 跨尺度一致性 `cs` + 动态权重调度。
- **图 / 表 / 公式**：可在右侧用"竖向流程图"配合文字。
- **讲稿要点**：强调"两条解码器共享同一套编码特征，不是两个独立网络"。
- **现有 PPT 复用**：页 6（总体架构文字说明）复用+扩充。

### P11 · 端到端数据流 · `YFFC.forward` 伪代码
- **页码 / 归属**：P11 / Part 2
- **页面目标**：让懂代码的人 30 秒内看懂主流程。
- **版式建议**：左侧伪代码块（等宽字体、语法高亮），右侧 4 条注释说明。
- **标题区**：**端到端数据流 · YFFC.forward 伪代码**
- **正文要点（伪代码，可直接上屏）**：

```python
def forward(self, x):                      # x: [B, 1, H, W]
    x_bb1, x_bb2, x_bb3, x_bb4, x_c = self.encoder(x)
    #  Encoder: ResNet50 + Swin 融合 + top-down 回流 + FFC 瓶颈 + 高频增强
    xe1, xe2, xe3, xe4, g, s = self.gradient_decoder(
        (x_bb1, x_bb2, x_bb3, x_bb4), x_c, x)
    #  xe_i: 供增强层使用的结构特征；g: 输入梯度；s: 高光软概率
    enh1, enh2, enh3, enh4 = self.enhancement_layers(
        (xe1, xe2, xe3, xe4), g, x, s)
    #  三路门控 + 频域精炼，把结构特征转成高光判别增强特征
    b, r_direct, alpha_logit = self.main_decoder(
        (x_bb1, x_bb2, x_bb3, x_bb4, x_c), (enh1, enh2, enh3, enh4), g, s, x)

    r_sub  = torch.clamp(x - b, 0, 1)                    # 物理一致性路径
    alpha  = torch.sigmoid(alpha_logit)                  # 可学习融合权重
    r_fuse = alpha * r_direct + (1 - alpha) * r_sub
    r      = self.refinement_head(r_fuse, x, r_direct)   # 残差精修
    cs     = cross_scale_consistency_loss(
        (x_bb2, x_bb3, x_bb4))                           # 训练辅助标量
    return {"r": r, "b": b, "g": g, "s": s,
            "r_direct": r_direct, "alpha": alpha, "cs": cs}
```

- **图 / 表 / 公式**：右侧注释：① `cs` 只用于训练；② `x` 既是输入也是残差参考；③ `alpha` 是逐像素图不是标量；④ 推理主输出为 `r/g/b`。
- **数据来源 / 需补充**：`X_FFC_unified.py` 的 `YFFC.forward`（L2850）与 `decoupled_yffc\README.md`。
- **讲稿要点**："注意 `r_sub` 这条减法路径——后面 P28/P29 会讲为什么要再补一条 `r_direct`。"

### P13 · 设计思想：三大设计抉择及其理由
- **页码 / 归属**：P13 / Part 2
- **页面目标**：把"为什么这么设计"讲成 3 个可记住的决策。
- **版式建议**：三张纵向卡片，每卡"问题 → 抉择 → 代价与收益"。
- **标题区**：**三大设计抉择 · 问题、选择与理由**
- **正文要点**：
  - **抉择一：为什么用频域（FFC）而不只是更深的空间卷积？**
    - 问题：高光破坏的是**跨整幅图像的周期结构**，纯局部卷积感受野不足，无法从"周围未污染条纹"推断"被破坏处本应是什么";
    - 抉择：引入 FFC，特征通道分局部（普通卷积，管纹理/边缘）与全局（FFT→频域卷积→iFFT，管周期结构）；频域一个系数影响空间域全局结构，天然全局感受野；
    - 收益：更强的正弦条纹恢复、更强相位一致性、更强全局补全能力、更强高光成分分离。
  - **抉择二：为什么需要 Swin-Tiny 与 ResNet50 双分支？**
    - 问题：ResNet 强于局部纹理/边缘，但对"窗口化长程关系"建模弱；纯 Transformer 在小样本、单通道条纹上易丢细节；
    - 抉择：ResNet50 出多尺度 skip 保细节，Swin-Tiny 出窗口上下文，在 H/4、H/8 轻量注入（`AdaptiveSkipFusion`，`beta` 初始化 0.03/0.05），在 H/16 双向交叉融合（先做 modality norm 对齐 CNN/Transformer 统计）；
    - 收益：局部细节与全局上下文兼得；`beta` 可学习且有日志监控（`fuse_h4.beta` / `fuse_h8.beta`）。
  - **抉择三：为什么不只用"减法"恢复漫反射？**
    - 问题：`r = clamp(x − b)` 链路过脆——若真实 `b = 0.5`，预测 `b = 0.6` 会让 `r` 偏暗 0.1；预测 `b = 0.3` 会残留 0.2 的高光，误差被 `b` 直接放大；
    - 抉择：保留物理一致性路径 `r_sub`，同时增加直接预测路径 `r_direct`，用可学习 `alpha`（逐像素）融合，再用 `ResidualRefinementHead` 做像素级小残差修正（默认残差尺度 0.08）；
    - 收益：既有物理约束，又不完全依赖 `b` 的估计精度；`r_direct` 与最终 `r` 之间还有一致性约束 `l_r_dual_cons`。
- **图 / 表 / 公式**：卡片三可配一张"减法链误差放大示意"（`b=0.5` 时 `b̂=0.3/0.6` 两条分支的 `r_sub` 差异）。
- **数据来源 / 需补充**：抉择一/二见 `docs\Y_FFC_X_FFC_频域_梯度_详细分析总结_最终版.md` 与 `YFFC_pipeline_issue_summary.md` 第 101–111 行；抉择三见 `docs\YFFC_关键模块问答总结.md` 双头设计段与 `YFFC_pipeline_issue_summary.md` 第 61–65 行。
- **讲稿要点**：这页是"答辩防守页"，三个抉择几乎覆盖所有"为什么不用 XX"的提问。

### P14 · Encoder · 双分支多尺度融合架构图
- **页码 / 归属**：P14 / Part 3
- **页面目标**：看懂"两条支路在哪里汇合、汇合后怎么走"。
- **版式建议**：整页横版图：上支路 ResNet50 四级，下支路 Swin 三级，中间标注 3 个融合点（H/4、H/8、H/16），右侧接瓶颈链。
- **标题区**：**Encoder · ResNet50 与 Swin-Tiny 的双分支多尺度融合**
- **正文要点**：
  - ResNet50 分支：`x → x_bb_1 (H/2) → x_bb_2 (H/4) → x_bb_3 (H/8) → x_bb_4 (H/16)`，全部作为主解码器 skip。
  - Swin-Tiny 分支：**直接处理单通道 patch，不强制 resize 到 224×224**，仅在尺寸不能被 32 整除时做右侧/下侧 padding（padding 模式优先 `reflect`，不满足时退回 `replicate`），输出 `swin_4 / swin_8 / swin_16`。
  - 融合点 1（H/4）：`AdaptiveSkipFusion(x_bb_2, swin_4)`，`beta` 初始 0.03。
  - 融合点 2（H/8）：`AdaptiveSkipFusion(x_bb_3, swin_8)`，`beta` 初始 0.05。
  - 融合点 3（H/16）：`swin16_proj (384→512)` → `CrossModalFusion(x_bb_4, swin_16)`，进入前对两模态先做无参数 modality norm。
  - 瓶颈链：`fused → cba_after_backbone → FFC bottleneck → HighFrequencyEnhancement → x_c [B,256,H/16,W/16]`。
  - 深层回灌：`CrossScaleTopDownRefinement` 执行 H/16 → H/8 → H/4 的受限残差回流，更新 `x_bb_2/x_bb_3/x_bb_4`。
- **图 / 表 / 公式**：图中用虚线区分"融合前 skip"与"回流后 skip"（强调主解码器拿到的是**回流更新后**的特征）。
- **数据来源 / 需补充**：`decoupled_yffc\README.md` 第 61–72 行；`README.md`（Swin 不 resize 的理由）。
- **讲稿要点**：解释"不 resize"的关键原因——resize 会压缩条纹细节、改变条纹频率/周期与局部相位关系、模糊高光边界、破坏相位恢复所需的空间采样一致性。

### P15 · ResNet50 局部纹理分支 · 结构与数据流
- **页码 / 归属**：P15 / Part 3
- **页面目标**：说明 ResNet 分支在"高反光条纹"任务里承担什么角色，输出五路特征各自用途。
- **版式建议**：左侧网络级联图（Conv→四个 stage），右侧"五路输出用途表"。
- **标题区**：**ResNet50 局部纹理分支 · 结构、输出与用途**
- **正文要点**：
  - 输入单通道 `[B,1,H,W]`（首层适配灰度输入），逐级下采样得到 64/128/256/512 通道特征。
  - 五路输出与用途：

| 输出 | 尺寸 | 通道 | 用途 |
|---|---|---|---|
| `x_bb_1` | H/2 | 64 | 最高分辨率细节 skip（用于 H/2 级解码） |
| `x_bb_2` | H/4 | 128 | 中细节 skip（H/4 级解码）；并被 `Swin_4` 增强 |
| `x_bb_3` | H/8 | 256 | 中层语义 skip（H/8 级解码）；并被 `Swin_8` 增强 |
| `x_bb_4` | H/16 | 512 | 深层语义 skip（H/16 级解码）；与 `Swin_16` 交叉融合 |
| `x_c` | H/16 | 256 | 编码瓶颈，主/梯度解码器的共同起点 |

  - 为什么是 ResNet：局部纹理、条纹灰度过渡、边缘与高光边界首先表现为**局部高频结构**，卷积归纳偏置最合适。
  - 为什么保留四级 skip：解码器需要从 H/2 到 H/16 的完整尺度阶梯，条纹细节与高光边界都要在浅层被精确恢复。
- **图 / 表 / 公式**：表格即正文；图中标注 `replace_bn_with_gn`（训练时 BN→GN，`num_groups=8`，缓解小 batch 统计不稳）。
- **数据来源 / 需补充**：`README.md`；`X_FFC_unified.py` 的 `Encoder`（L2134）；`decoupled_yffc\README.md` 第 8 行（BN→GN）。
- **讲稿要点**："ResNet 只管'细节在哪里'，全局上下文交给 Swin 和 FFC。"

### P16 · Swin-Tiny 分支、跨模态融合与受限回灌
- **页码 / 归属**：P16 / Part 3
- **页面目标**：讲清三件事——Swin 如何适配单通道与任意尺寸、如何与 CNN 融合、为什么还要 top-down 回灌。
- **版式建议**：上：Swin 适配要点（3 条）；中：两个融合模块结构小图并排（`AdaptiveSkipFusion` / `CrossModalFusion`）；下：`CrossScaleTopDownRefinement` 三步示意。
- **标题区**：**Swin-Tiny 多尺度上下文 · 跨模态融合与深层回灌**
- **正文要点**：
  - **单通道适配**：Swin 输入为 1 通道条纹 patch；不 resize，只在尺寸不可被 32 整除时 pad 到 32 的倍数。
  - **`AdaptiveSkipFusion`（H/4、H/8 用）**：把 Swin 特征投影到 CNN 通道数后，以可学习标量 `beta` 做残差注入：`x_bb = x_bb + beta · Proj(swin)`；`beta` 初值 0.03（H/4）、0.05（H/8），训练日志打印 `fuse_h4.beta`、`fuse_h8.beta`，便于观察"模型到底有没有用上 Swin"。
  - **`CrossModalFusion`（H/16 用）**：`swin16_proj` 把 384 通道投到 512；进入交叉注意力前，对 CNN 特征与 Transformer 特征各自做**无参数 modality norm**，缓解两者统计差异；再做双向交叉注意力融合。
  - **`CrossScaleTopDownRefinement`（受限回灌）**：
    1. H/16 自身精炼：`h16_ctx = Conv3×3_BN_ReLU(h16)`，`h16_out = h16 + gamma · h16_ctx`；
    2. H/16 → H/8：`h8_from_h16 = Upsample(Conv1×1(h16_ctx))`（512→256）；门控 `h8_gate = Sigmoid(Conv1×1(concat(h8, h8_from_h16)))`；`h8_out = h8 + gamma · h8_gate · h8_from_h16`；
    3. H/8 → H/4：同构（256→128）。
    - `gamma` 为可学习残差强度，初值 0.05，且 **clamp 到 [0, 0.2]**，保证是"轻量回流"而非强行改写浅层 skip。
  - **回灌解决什么问题**：浅层只看得到"局部亮边"，不知道它是否与高光相关；把 H/16 的全局上下文与高光判断逐级回流，可增强浅层语义判断、减少多尺度特征冲突、让主/梯度解码器拿到更一致的 skip，最终降低高光残留与"正常条纹被误去除"。
- **图 / 表 / 公式**：回灌三步用流程小图；旁边配一句"为什么 clamp 到 0.2"——稳定优先，避免破坏浅层细节。
- **数据来源 / 需补充**：`docs\YFFC_关键模块问答总结.md`（CrossScaleTopDownRefinement 逐字细节）；`YFFC_pipeline_issue_summary.md` 第 118–123 行。
- **讲稿要点**：主动提一句"这是本版本相对上一版新增的结构，配合跨尺度一致性损失一起用"。
- **现有 PPT 复用**：页 12（Swin 分支）+ 新增回灌内容。

### P17 · FFC 频域卷积核心 · 三层封装（分隔页 + 层级总览）
- **页码 / 归属**：P17 / Part 4（含章节分隔视觉）
- **页面目标**：建立"FFC 是嵌套三层"的正确心智模型。
- **版式建议**：左侧大号章节标题（深底白字），右侧嵌套方框图（外→内三层）。
- **标题区**：**FFC 频域卷积核心**
- **正文要点**：
  - 三层嵌套关系（注意：是**嵌套**，不是并列）：
    `FFC_BN_ACT`（最外层，模型统一入口） → `SpectralTransform`（中间层） → `FourierUnit`（最底层频域单元）。
  - 模型内所有频域能力都经由 `FFC_BN_ACT` 进入，不要在汇报里把三者说成三个平行模块。

    1. 编码器瓶颈：`ffc_bottleneck`；
    2. 梯度解码器：多尺度频域处理；

    4. 增强层：`_SpectralDecompositionUnit` 内的 specular 分支频域精炼；
    5. 损失：频域损失约束幅度与准相位一致性；
    6. 高频增强：`HighFrequencyEnhancement` 显式强化边缘/跃变/高光边界。
- **图 / 表 / 公式**：嵌套方框图；右侧可放"FFC 出现位置"的模型缩略图（6 个红点标注）。
- **数据来源 / 需补充**：`docs\YFFC_关键模块问答总结.md` FFC 层级段；`docs\Y_FFC_X_FFC_频域_梯度_详细分析总结_最终版.md`（8 点频域增强）。
- **讲稿要点**："频域不是在某处加一次 FFT，而是**多尺度全链路体系**。"
- **现有 PPT 复用**：页 14（分隔页）+ 页 15（三层封装）合并。

### P18 · FFC_BN_ACT · 局部/全局四路交互
- **页码 / 归属**：P18 / Part 4
- **页面目标**：讲清最外层模块如何把"局部卷积"与"频域全局卷积"耦合起来。
- **版式建议**：左：四路交互示意图（L→L、L→G、G→L、G→G）；右：关键点文字。
- **标题区**：**FFC_BN_ACT · 局部与全局的四路交互**
- **正文要点**：
  - 输入特征按通道拆成两部分：`x_l`（局部分支，走普通卷积）与 `x_g`（全局分支，走频域）。
  - 四路交互：
    - `L → L`：普通 `Conv2d`，保持局部纹理与边缘；
    - `L → G`：`Conv2d`，把局部信息注入全局分支（让频域也"知道"局部细节）；
    - `G → L`：`SpectralTransform`，把全局周期信息回灌到局部；
    - `G → G`：`SpectralTransform`，全局分支内部做频域卷积。
  - 输出：`out_xl = activation(BN(out_xl))`，`out_xg = activation(BN(out_xg))`，返回两个分支（保持局部/全局解耦结构，供上层继续使用）。
  - 设计意图：**局部管"细节对不对"，全局管"周期对不对"**；四路交互避免两支路各自为政。
  - 激活函数用 **GELU 而非 ReLU**：ReLU 会把频域负值直接置零，破坏相位信息；GELU 保留负值区间的平滑响应，对相位恢复更友好。
- **图 / 表 / 公式**：四路交互图；公式行 `out = (out_l, out_g)`，`out_l = act(BN(LL(x_l) + GL(x_g)))`。
- **数据来源 / 需补充**：`X_FFC_unified.py` 的 `FFC_BN_ACT` L325（forward L403）。
- **讲稿要点**："GELU 这个细节看起来很小，但对频域相位是关键的。"
- **现有 PPT 复用**：页 17（SpectralTransform 与 FFC_BN_ACT 封装详解）拆分改写。

### P19 · FourierUnit · 最底层频域单元的 7 步流水线
- **页码 / 归属**：P19 / Part 4
- **页面目标**：给出可复现的频域单元实现流水线，体现工程严谨性。
- **版式建议**：横向 7 步流程图（每步图标 + 一行说明），下方标注两个亮点（Tukey、频域 SE）。
- **标题区**：**FourierUnit · 频域单元的 7 步流水线**
- **正文要点（7 步）**：
  1. **Tukey 窗加窗**：`_tukey_window(size, alpha=0.25)`，减少 FFT 边界不连续造成的**频谱泄漏**；
  2. **`rFFT`**：实数输入 → 频域（利用共轭对称，只算一半）；
  3. **实部/虚部通道拼接**：把复数变成 2C 通道的实张量，便于用卷积处理；
  4. **`1×1 Conv`**：在频域上做逐点通道混合（这才是"频域卷积"的实质）；
  5. **`BatchNorm`**：稳定频域特征分布（训练时被 `replace_bn_with_gn` 统一替换为 GN）；
  6. **`GELU` + **频域 SE 注意力**：自适应选择有用频段（哪些频率该增强、哪些该压）；
  7. **复数重组 + `iRFFT`**：回到空间域，输出与输入同尺寸。
- **图 / 表 / 公式**：流程图；旁边放"Tukey 窗 vs 矩形窗"的频谱对比小图（⚠️ 需本地生成）。
- **数据来源 / 需补充**：`X_FFC_unified.py` 的 `FourierUnit` L133（forward L179）、`_tukey_window` L98。
- **讲稿要点**：强调第 1 步和第 6 步是本版本的工程细节亮点，一般 FFC 实现里没有。
- **现有 PPT 复用**：页 16（FourierUnit 7 步流水线）复用+补显著性说明。

### P20 · SpectralTransform · 中外两层封装详解 + 频域 8 项增强总结
- **页码 / 归属**：P20 / Part 4
- **页面目标**：补齐中间层结构，并把"频域到底强在哪"浓缩成一页清单。
- **版式建议**：上半页 `SpectralTransform` 内部结构图；下半页"频域 8 项增强"清单（2×4 卡片）。
- **标题区**：**SpectralTransform · 中间层封装与频域增强 8 项清单**
- **正文要点**：
  - `SpectralTransform` 内部顺序：
    `1×1 Conv 降维` → `FourierUnit`（全局频域卷积） → `FourierUnit`（LFU top，局部频域） → `FourierUnit`（LFU bottom，局部频域） → **FU/LFU 门控融合** → `1×1 Conv 升维`。
    - 设计意图：全局 FU 抓"整幅条纹的周期结构"，两个局部 FU（按通道切分 top/bottom）抓"局部频域细节"，再用门控融合两者——避免纯全局卷积丢掉局部高光边界。
  - **本工作频域增强 8 项**：
    1. `FourierUnit`：空间→频域→频域卷积→空间；
    2. `SpectralTransform`：全局 FU + 局部 LFU 组合；
    3. `FFC_BN_ACT`：局部/全局四路交互；
    4. **GELU 替代 ReLU**：保护频域负值与相位信息；
    5. **频率 SE 注意力**：自适应选择有用频段；
    6. **Tukey 窗**：减少 FFT 边界不连续导致的频谱泄漏；
    7. `HighFrequencyEnhancement`：显式增强边缘、跃变、高光边界；
    8. **频域损失**：约束幅度与准相位一致性。
  - 收尾一句（回扣 P7/P8）："高反光让频谱变脏（低频/高频/谐波同时增加），FFC 的全局频域建模正是对这三类污染的统一回应。"
- **图 / 表 / 公式**：结构图 + 8 卡片；可选在公式区写"频域卷积等价于全局空间卷积，但参数量与感受野关系不同"。
- **数据来源 / 需补充**：`docs\YFFC_关键模块问答总结.md`；`docs\Y_FFC_X_FFC_频域_梯度_详细分析总结_最终版.md`。
- **讲稿要点**：这是 Part 4 收尾页，用于把"频域"打包成一个完整能力清单，方便评审记住。

## 6. 第六部分：梯度辅助分支（P21–P24）

### P21 · 梯度分支动机（分隔页）：梯度监督目标为什么改成输入梯度
- **页码 / 归属**：P21 / Part 5（含分隔视觉）
- **页面目标**：把 V3.1 的关键改动讲成一次"有理由的语义升级"。
- **版式建议**：左侧分隔标题；右侧上下对比卡（旧：`Sobel(I_d)` / 新：`Sobel(I)`）+ 3 条理由。
- **标题区**：**梯度辅助分支 · 从拟合漫反射梯度到拟合输入梯度**
- **正文要点**：
  - **旧做法**：梯度分支拟合 `Sobel(I_d)`（去高光后的漫反射梯度）。
  - **新做法（V3.1 起）**：拟合 `Sobel(I)`（输入图像梯度），由 `compute_input_gradient_target(input_img)` 生成。
  - **理由**：
    1. 高光边界、饱和平台边缘、非过曝污染区的异常变化**首先存在于输入图像中**，在漫反射目标里已经被"洗掉"；
    2. 输入梯度比漫反射 GT 梯度更直接指出"哪里出现了高反光相关异常"；
    3. 输出 `g` 仍是**网络预测**（不是推理时直接算 Sobel），因此推理阶段不依赖任何标签。
  - **注意点**：`Sobel(I)` 语义是混合的（普通条纹边缘 + 物体轮廓 + 高光边界 + 噪声），所以"只拟合梯度"不够，必须有后续的**高光判别**机制（→ P23 的 `s` 头、P26 的三路门控）。
- **图 / 表 / 公式**：对比卡；公式 `g_target = |∇I|`（`normalized_sobel_magnitude`，分位数 0.995 归一化）。
- **数据来源 / 需补充**：`docs\模型讲解\YFFC_输入梯度语义对齐改造详细方案.md` 第 13–19、26–43 行。
- **讲稿要点**："改监督目标是升级，不是修补——但只改监督目标不够，这就是 V3.2 继续做增强层判别的原因。"
- **现有 PPT 复用**：新增页（旧版缺此演进说明）。

### P22 · GradientDecoder · 5 级 Block 与双任务输出
- **页码 / 归属**：P22 / Part 5
- **页面目标**：讲清梯度解码器的整体结构和两个并列头。
- **版式建议**：左侧 5 级解码结构图；右侧"双头输出对照表"。
- **标题区**：**GradientDecoder · 5 级 Block 与双任务输出**
- **正文要点**：
  - 输入：ResNet 四级 backbone 特征 + 瓶颈 `x_c` + 原图 `x`（`forward(self, backbone_features, x_c, original_input=None)`）。
  - 主体：5 级解码（含多尺度频域处理），逐级上采样到 H。
  - 尾部**两个并列头**：
    - **梯度头** → 输出 `g [B,1,H,W]`，监督目标 `Sobel(I)`；
    - **高光概率头** → 输出 `s [B,1,H,W]`（0~1 软概率），监督目标 `gt_specular = clamp(I − I_d, 0, 1)`。
  - `b` 与 `s` 的本质区别（务必讲清）：

| 输出 | 回答的问题 | 类型 | 举例（`I=0.9`，`I_d=0.4`） |
|---|---|---|---|
| `b`（主解码器） | 这个位置**应该减掉多少**高光 | 强度图 | 理想 `b ≈ 0.5` |
| `s`（梯度分支） | 这个位置**是不是**高光区域 | 软概率图 | 理想 `s ≈ 0.8~1.0` |

### P26 · `_SpectralDecompositionUnit` · 单元内部 6 步流程
- **页码 / 归属**：P26 / Part 7
- **页面目标**：这是全模型"最具本工作特色"的模块之一，需讲透。
- **版式建议**：左侧 6 步竖向流程；右侧 3 个门控公式卡。
- **标题区**：**`_SpectralDecompositionUnit` · 结构特征到高光判别特征的 6 步转译**
- **正文要点**：
  - 实例配置：`decomp_unit_1(256→128)`、`_2(128→64)`、`_3(64→32)`、`_4(32→16)`。
  - 6 步流程：
    1. **双分支分解**：`projection = Conv7×7_BN_ReLU(x)`（大核，抓结构/低频形态）；`specular = Conv3×3_BN_ReLU(x)`（小核，抓局部高光细节）；
    2. **specular 分支频域精炼**：把 `specular` 按通道拆成局部 L / 全局 G → 过 `FFC_BN_ACT` → 残差回加：`specular = FFC_out + specular`；
    3. **自门控融合**：`gate = Sigmoid(Conv1×1(concat(projection, specular)))`，`specular_refined = specular + specular · gate`（让投影分支告诉 specular 分支"哪里值得保留"）；
    4. **先验对齐**：把 `g_map`、`original_input`、`s_map` 双线性 resize 到当前特征尺寸；
    5. **双门控构造**：
       - `edge_gate = Sigmoid(Conv3×3(g_down))` —— "哪里发生了结构突变"；
       - `spec_gate = Sigmoid(Conv3×3(concat(g_down, input_down, s_down)))` —— "哪些突变更像高反光"；
       - `final_gate = edge_gate × spec_gate` —— **两级串联判别**；
    6. **门控输出**：`output = specular_refined + beta · specular_refined · final_gate`，`beta` 可学习并限制在 [0, 1]，保证是"增强"而非"替换"。
  - 为什么这样设计：如果只用 `edge_gate`，普通物体边缘也会被强化；加上 `spec_gate`（含亮度与 `s` 先验）后，只有"既有梯度突变又像高光"的位置才被增强——这就是 P24 中失配 A/B 的正解。
- **图 / 表 / 公式**：6 步流程图；三个门控公式上屏。
- **数据来源 / 需补充**：`docs\YFFC_关键模块问答总结.md`（`_SpectralDecompositionUnit` 逐字细节）；`X_FFC_unified.py` L2653（forward L2712）。
- **讲稿要点**：这是"物理先验 + 有监督语义"结合得最紧的一块，建议多花 30 秒。
- **现有 PPT 复用**：页 24（4 级并列单元 + 单元内部结构）、页 26（单元内部 5 步流程）合并升级为 6 步。

### P28 · 双头输出与双路融合 + 残差精修（核心页）
- **页码 / 归属**：P28 / Part 7
- **页面目标**：把"减法链脆弱 → 双路径恢复"讲成整片最有说服力的工程设计。
- **版式建议**：上半页双头结构图（`output_conv4 → b`、`output_r_direct_conv → r_direct`、`alpha_logit`）；下半页融合公式带 + 数值示例卡。
- **标题区**：**双路漫反射融合 + ResidualRefinementHead**
- **正文要点**：
  - 三个输出：
    - `b = output_sigmoid(output_conv4(x))` —— 镜面反射分量（强度图）；
    - `r_direct = output_r_direct_sigmoid(output_r_direct_conv(x))` —— 直接预测的漫反射；
    - `alpha_logit` —— 逐像素融合权重。
  - 融合与精修：
    - `r_sub  = clamp(x − b, 0, 1)`（物理一致性路径）
    - `alpha  = sigmoid(alpha_logit)`（可学习、逐像素）
    - `r_fuse = alpha · r_direct + (1 − alpha) · r_sub`
    - `r      = ResidualRefinementHead(r_fuse, x, r_direct)`（残差尺度默认 0.08）
  - **为什么必须双路**（数值示例，建议直接上屏）：

| 情形 | `r_sub = clamp(x − b̂)`（`x = 0.9`，理想 `b = 0.5`） | 后果 |
|---|---|---|
| 预测 `b̂ = 0.5` | 0.4 | 正确 |
| 预测 `b̂ = 0.6` | 0.3 | 偏暗 0.1 |
| 预测 `b̂ = 0.3` | 0.6 | 残留 0.2 高光 |

  - 结论：单点误差被"减法链"直接放大到 `r`；`r_direct` 提供不依赖 `b` 的恢复路径，`alpha` 让网络自己决定每像素该信哪条路，`refinement_head` 再做小残差修正。
  - 已有 **6 项软耦合**（保证两条路不各走各的）：① `b` 受 `gt_specular` 监督；② `r` 受目标图像监督；③ `b` 经 `r_sub` 影响最终 `r`；④ `r_direct` 经 `r_fuse`/精修影响最终 `r`；⑤ `r_direct` 与最终 `r` 有一致性约束（`l_r_dual_cons`）；⑥ `s` 与 `b` 有一致性约束。
- **图 / 表 / 公式**：融合公式带 + 示例表；可加一句"设计意义 = 物理一致性路径 + 直接恢复路径 + 残差精修"。
- **数据来源 / 需补充**：`docs\YFFC_关键模块问答总结.md`；`X_FFC_unified.py` 的 `ResidualRefinementHead` L2760（forward L2790）；`YFFC_pipeline_issue_summary.md` 第 61–65 行。
- **讲稿要点**：这页可以主动说"我们**没有**硬约束 `r_direct + b ≈ x`"，理由见 P55（未来工作）——先埋钩子。

### P31 · 高光感知注意力两件套：SpecularAwareAttention 与 Attention_block
- **页码 / 归属**：P31 / Part 7
- **页面目标**：消除"两个注意力有什么区别、顺序为什么这样"的疑问。
- **版式建议**：左右两个模块结构卡 + 底部一行"配合顺序"流程条。
- **标题区**：**两类注意力机制 · 一个管"关注高光"，一个管"筛选 skip"**
- **正文要点**：
  - **`SpecularAwareAttention`（decoder feature specular enhancer）**
    - 输入：当前解码特征 + 原图；`forward(self, features, original_input)`；
    - 高光先验：`spec_prior = 0.75 · brightness + 0.25 · local_contrast`；其中 `local_contrast = |input − avg_pool(input)|`；
    - 多阈值 mask：0.5（弱）/ 0.7（中）/ 0.9（强）三档，拼到特征上；
    - 结构：`concat(features, multi_mask)` → 3×3 Conv+BN+GELU → 3×3 Conv+BN → Sigmoid → 输出 `features · (1 + scale · att)`（`scale` 可学习且限制在较小范围）；
    - 4 个实例：`sa1(H/16)`、`sa2(H/8)`、`sa3(H/4)`、`sa4(H/2)`，位置：**各级 `transposed_block` 之后、`Attention_block` 之前**。
    - 为什么加 `local_contrast`：只用亮度会把"亮的漫反射区域"误判为高光（旧版问题，现为"已缓解"）。
  - **`Attention_block`（skip connection filter）**
    - 代码：`g1 = W_g(g); x1 = W_x(x); psi = relu(g1 + x1); psi = psi_conv(psi); return x * psi`；
    - 术语澄清（**必讲**）：这里的 `g` 是 **gating signal = 当前 decoder 特征**，`x` 是 **encoder skip 特征**；与梯度图 `g`、高光概率 `s` 无关，只是命名巧合；
    - `W_g`/`W_x` 为 1×1 Conv+BN，`psi` 为 1×1 Conv+BN+Sigmoid；
    - 4 个实例：`att1(H/16, x_bb_4)`、`att2(H/8, x_bb_3)`、`att3(H/4, x_bb_2)`、`att4(H/2, x_bb_1)`；
    - 解决的问题：避免把"高光边界残留、局部噪声、过亮条纹、与当前目标不一致的浅层细节"无条件带回解码器。
  - **配合顺序**：当前解码特征 → `SpecularAwareAttention`（让特征更关注高光） → `Attention_block`（用增强后的特征筛选 skip 得到 `bridge`） → `concat(x, bridge, enh_i)`。
- **图 / 表 / 公式**：两卡 + 流程条；建议在 `Attention_block` 卡上加红框标注"此 g 非彼 g"。
- **数据来源 / 需补充**：`X_FFC_unified.py` 的 `SpecularAwareAttention` L1782（forward L1815）、`Attention_block` L543（forward L570）；`YFFC_pipeline_issue_summary.md` 第 90–94 行。
- **讲稿要点**：顺序不能反——先"让特征知道高光在哪"，再"用它去挑 skip"，否则筛选依据里没有高光语义。
- **现有 PPT 复用**：页 35（两类注意力机制）复用+补"此 g 非彼 g"澄清。

### P32 · 高光融合与梯度门控的两处实现细节
- **页码 / 归属**：P32 / Part 7
- **页面目标**：补充主解码器里"梯度/高光到底怎么调制特征"的具体机制，回答"注入强度是否可控"。
- **版式建议**：左右两卡（三路门控调制 / 高频增强），底部一句"可学习强度都有限幅"。
- **标题区**：**主解码器内的调制机制 · 梯度门控与高频增强**
- **正文要点**：
  - **三路门控调制**（H/8、H/4、H/2 各级）：用 `g`（梯度，管"结构突变"）、`input`（亮度，管"是否过曝/高亮"）、`s`（高光概率，管"是否高光相关"）生成门控，对解码特征逐通道调制。相比旧版只用一个梯度门控 `x · (1 + grad_gate(x_g))`，三路门控显式解决了"强梯度 ≠ 高反光"的歧义（对应 P24 失配 B）。
  - **`HighFrequencyEnhancement`**：位于编码器瓶颈链末端（`cba_after_backbone → FFC bottleneck → hf_enhance`），显式增强边缘、跃变与高光边界——弥补纯频域建模对"尖锐局部跃变"的响应不足。
  - **可学习强度均有限幅**：`AdaptiveSkipFusion.beta`（小正数初值）、`CrossScaleTopDownRefinement.gamma`（clamp 0~0.2）、`_SpectralDecompositionUnit.beta`（限制 0~1）、`SpecularAwareAttention.scale`（限制在较小范围）——目的是保证结构改动"温和可归因"，不会因某个门控发散而毁掉训练。
  - **训练侧监控**：日志打印 `fuse_h4.beta`、`fuse_h8.beta` 与 gate mean，用于确认"这些门控真的在被使用"而不是退化为 0。
- **图 / 表 / 公式**：三路门控公式 `x = x · gate(g, input, s)`；限幅参数一览小表。
- **数据来源 / 需补充**：`X_FFC_unified.py` 的 `HighFrequencyEnhancement` L1834（forward L1880）；`YFFC_pipeline_issue_summary.md` 第 96–116 行；`decoupled_yffc\README.md` 第 116 行。
- **讲稿要点**："所有新增门控都限幅，这是为了让每次结构改动都能归因、可回退。"
- **现有 PPT 复用**：新增页（旧版分散在 Encoder / 主解码器页）。

### P38 · 训练流程细节：优化、调度与稳定性
- **页码 / 归属**：P38 / Part 7
- **页面目标**：把训练工程细节一次讲全，体现可复现性。
- **版式建议**：四象限卡片（优化器 / 调度 / 稳定性 / checkpoint）。
- **标题区**：**训练流程 · 优化、调度、稳定性与 checkpoint 口径**
- **正文要点**：
  - **默认超参**：`EPOCHS = 50`、`BATCH_SIZE = 3`、`ACCUMULATION_STEPS = 3`、`BASE_LR = 2e-4`、`GRAD_CLIP_VALUE = 1.0`、`weight_decay = 1e-4`、`IMAGE_SIZE = (128,160)`、`USE_AMP = False`。
  - **分层学习率 `build_optimizer_v2`**：
    - `encoder.swin_branch.swin` 用 **0.1× base_lr**（预训练主干，微调要慢）；
    - 新增模块组（`fuse_h4`、`fuse_h8`、`swin16_proj`、`refinement_head`、`top_down_refine`）用 **1.0× base_lr**；
    - 训练日志按**命名参数组**逐组打印 LR（`format_lr_groups()`），不再只看第一组。
  - **调度器 `build_scheduler`**：warmup（500 iters）+ cosine；**`iters_per_epoch` 与 warmup 步数按 `ceil(len(loader) / accumulation_steps)` 计算**，确保 scheduler 只在真实 `optimizer.step()` 后推进（否则梯度累积会让学习率"走快"）。
  - **稳定性措施**：
    - **BN → GN**：`replace_bn_with_gn(model, num_groups=8)`，解决小 batch（3）下 BN 统计不稳定的问题，默认开启（`USE_GN = True`）；

### A2 · 公式速查页
- `I_i = A + B·cos(φ + δ_i)`（N 步相移成像模型）
- `I = I_d + I_s`（反射分解）
- `I = A + Σ_{i=1..k} B_i·cos(iφ), k > 1`（高反光非正弦展开）
- `∇I = ∇A + ∇B·cos(φ+δ) − B·sin(φ+δ)·∇φ + ∇I_s`
- `dI/dx = −2πfB·sin(2πfx + φ)`（理想条纹梯度）
- `F{dI/dx} = j2πf·F{I}`（求导放大高频）
- `x_bb = x_bb + beta · Proj(swin)`（AdaptiveSkipFusion）
- `h16_out = h16 + gamma · h16_ctx`；`h8_out = h8 + gamma · h8_gate · h8_from_h16`（受限回灌）
- `final_gate = edge_gate × spec_gate`；`output = specular_refined + beta · specular_refined · final_gate`
- `r_sub = clamp(x − b, 0, 1)`；`alpha = sigmoid(alpha_logit)`；`r_fuse = alpha·r_direct + (1−alpha)·r_sub`
- `cs = 0.5·(L1(resp_H/4, resp_H/8) + L1(resp_H/8, resp_H/16))`
- `gt_specular = clamp(input − target, 0, 1)`
- `L_total = Σ λ_i(t) · l_i`
